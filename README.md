# Base L2 Earning Agent

Complete skill package for automated earning on Base L2.

## Contents

- `SKILL.md` - Main skill instructions
- `README.md` - This file
- `scripts/miner.py` - Litcoiin mining automation
- `scripts/x402_server.py` - x402 monetization server
- `scripts/register.py` - Marketplace registration automation

## Installation

### Via Agensi (Recommended)
```bash
npx agensi install base-l2-earning-agent
```

### Manual Install
```bash
unzip base-l2-earning-agent.zip -d ~/.openclaw/skills/
```

## Quick Start

1. Set up your Base wallet
2. Configure API keys in `.env`
3. Run earning workflows
